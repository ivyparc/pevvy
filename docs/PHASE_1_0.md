# Phase 1.0 — Foundation & Design System

기준: 이전 PET 기획의 Phase 1.0 상세 구현 계획. 2026-10-14 구현.

**구현 및 자동 검증은 완료했습니다. iOS·Android 네이티브 기기 실행과 기기 접근성 점검은 미완료입니다.** 기획에 있던 양 플랫폼 실행 확인까지 완료된 것으로 간주하지 않습니다.

## 실제 검증 결과

- `pnpm check`: TypeScript·ESLint 오류/경고 없음, 4개 suite와 18개 테스트 통과.
- `EXPO_OFFLINE=1 pnpm exec expo install --check`: 고정된 SDK의 의존성 호환성 통과.
- `pnpm peers check`: peer dependency 충돌 없음.
- `pnpm export:all`: iOS·Android Hermes 번들과 웹 번들·17개 정적 경로 생성 통과.
- 브라우저 390×844 및 기본 크기에서 한국어·다크모드, 선택 상태 접근성, 새로고침 후 설정 유지 확인.
- 5개 탭 이동, Care 하위 화면과 뒤로 가기, 루트 진입 시 마지막 탭 복원 확인.
- 시트 입력·닫기·초점 복귀, 확인창 취소, 오프라인 상태 미리보기 확인.

## 남은 기기 검증

- iOS: Xcode 시뮬레이터와 Expo Go 설치까지 진행했지만, Expo CLI의 Simulator 활성화가 macOS 앱 제어 제한으로 실패했습니다. 실제 앱 화면과 VoiceOver·Dynamic Type·기기 키보드를 검증하지 못했습니다.
- Android: SDK·에뮬레이터가 없어 기기 실행을 수행하지 못했습니다. 뒤로 가기 시트 요청은 컴포넌트 테스트로만 확인했습니다.
- 양 플랫폼의 실제 설치·실행, 시트 키보드 회피, 큰 글자 크기·화면 회전, VoiceOver/TalkBack 읽기 순서, OS 테마 전환을 확인해야 합니다. 번들 성공은 기기 실행 성공을 의미하지 않습니다.

## 후속 Phase

인증·계정·개인 Household·서버 권한은 Phase 1.1, Pet 프로필 CRUD와 다중 Pet 선택은 Phase 1.2–1.3에서 연결합니다. 실제 Home 요약·기록·일정은 해당 데이터 기능이 구현된 뒤 완성합니다. Explore와 Shop은 공급자 데이터가 준비되기 전까지 준비 상태로 표시합니다.

실제 사용자·반려동물·건강·일정·장소·상품 데이터는 생성하지 않았고, 외부 서비스 계정과 배포도 설정하지 않았습니다.
